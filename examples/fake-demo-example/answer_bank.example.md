# Fictional example Answer Bank

Use answer_bank.template.json for execution. Keys are complete exact questions; entries contain approved, value and kind. No fuzzy sponsorship/legal matching. Confirm facts before approved=true.

Kinds: ordinary, work_authorization, sponsorship, salary, custom. Salary needs currency/period. Background checks, references, non-competes, identity documents and payment pause even if an answer exists. Unknown optional self-ID stays blank. Required custom questions need exact approved answers. Do not invent claims or silently adapt wording.
