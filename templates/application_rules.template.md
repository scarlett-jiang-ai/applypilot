# Private application rules

Default: discovery only; auto_submit_enabled=false. Existing resumes only.

Configure approved categories, locations, seniority, employment types, excluded employers/roles, authorization/sponsorship, salary range/currency/period, official hosts and browser scope in private policy/profile JSON. Unknowns block execution.

Freshness: P0 0–6h; P1 6–24h; P2 24–48h; P3 2–7d only for high fit. Unknown dates remain unknown; reposts do not reset them. Rank responsibilities, not titles. Funding alone is not an opening.

Only confirmed official ATS submissions count. Pause for unclear sensitive questions, failed uploads, changed/custom forms, login/2FA, CAPTCHA, permissions or payment. No LinkedIn Easy Apply or automatic outreach. See setup-workflow.md for approval/revocation.
